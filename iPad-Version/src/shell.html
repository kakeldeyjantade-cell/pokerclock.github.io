PokerclockTurnieruhr fürs iPad, gesteuert vom Handy

Wie nutzt du dieses Gerät?

Die Online-Verbindung ist hier nicht verfügbar. Öffne die Pokerclock in claude.ai, angemeldet mit deinem Konto. Als Host läuft die Uhr trotzdem, nur das Handy kann dann nicht steuern.

Dieses Gerät merkt sich die Wahl. Ändern geht später über das Menü (⋯ auf der Anzeige, „Turnier“ in der Steuerung).

PokerclockMit dem iPad verbinden

Code des iPads eingeben

Der Code steht auf dem iPad oben rechts, z. B. „Code AB12CD“. Einfacher: den QR-Code auf dem iPad mit der Kamera scannen, dann verbindet sich das Handy von selbst.

Bitte den Code vom iPad eingeben (6 Zeichen).
